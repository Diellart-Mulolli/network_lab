events per day N = 50,000,000; p = 1e-06; TPR = 0.95; FPR = 0.001; capacity = 60 alerts per
    analyst per day

method 1: expected counts per day
  malicious events         N*p          = 50.0
  benign events            N*(1-p)      = 49,999,950.00
  true alerts              N*p*TPR      = 47.50
  false alerts             N*(1-p)*FPR  = 49,999.95
  alerts per day                        = 50,047.45
  P(attack | alert) = 47.50 / 50,047.45 = 0.000949 = 0.0949 %  (one alert in 1,054 is real)
  analysts = 50,047.45 / 60 = 834.12 -> 835 analysts

method 2: Bayes' formula  P = TPR*p / (TPR*p + FPR*(1-p))
  P(attack | alert) = 0.000949   (difference to method 1: 0.0e+00)
  share of alerts that are false = 99.9051 %
